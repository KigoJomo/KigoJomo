# Jomo Kigo

[kigo.ke](https://kigo.ke) · [hello@kigo.ke](mailto:hello@kigo.ke) · [@KigoKe](https://x.com/KigoKe)

I build desktop apps, browser extensions, web tools, and the occasional small thing that solves one irritating problem.

## Public projects

- [TickTick Waybar](https://github.com/KigoJomo/ticktick-waybar) puts due-task counts, quick capture, and task completion in Waybar and Walker.
- [Browser Tweaks](https://github.com/KigoJomo/browser-tweaks) collects my small Chromium and Firefox fixes for GitHub, YouTube, fast.com, and link-opened tabs.
- [Windows Setup](https://github.com/KigoJomo/windows-setup) automates a quiet Windows 11 install, removes the usual bundled clutter, and installs my development tools.
- [Privacy Peek](https://github.com/KigoJomo/privacy-peek) reads website privacy policies and turns them into category scores that are easier to compare. [Open the site](https://privacy.experiments.kigo.ke).
- [Hand Terminal](https://github.com/KigoJomo/hand-terminal) is an early Expo prototype for a handheld Codex client.
- [Canton Fair Supplier Exporter](https://github.com/KigoJomo/cantonfair-supplier-app) collects suppliers from Canton Fair category pages and exports them to XLSX. [Open the app](https://cantonfair-supplier-app.vercel.app).
- [File Conversion](https://github.com/KigoJomo/file-conversion) converts batches of DOCX, XLSX, and PPTX files to PDF through CloudConvert. [Open the app](https://convert.aqutte.co.ke).
- [Audio Recorder](https://github.com/KigoJomo/audio-recorder) is a small browser MediaRecorder experiment.
- [Image Zoom](https://github.com/KigoJomo/image-zoom) is a dependency-free image zoom demo with tap-position zooming and hotspots.
- [Monorepo Task List](https://github.com/KigoJomo/shadcn-monorepo) keeps two task-list frontends, a shared Convex backend, and shared UI code in one Turborepo. [Open the comparison](https://tasks-monorepo.experiments.kigo.ke).
- [Notation Input](https://github.com/KigoJomo/notation-input) tests a direct-manipulation music notation editor with exact answer checking. [Open the prototype](https://notation.experiments.kigo.ke).
- [Codex Wrapper](https://github.com/KigoJomo/codex-wrapper) is an Electron reader for local Codex projects, thread history, tool activity, and diffs.
- [Electron + Vite](https://github.com/KigoJomo/electron-vite) is my starter for Electron, React, TypeScript, Tailwind, and shadcn/ui.
- [Simple Editor](https://github.com/KigoJomo/simple-editor) tests a shared Tiptap document backed by Convex ProseMirror Sync.
- [DevKit](https://github.com/KigoJomo/devkit) has small tools for UUIDs, slugs, URLs, prices, and Git commands. [Open the app](https://tools.aqutte.co.ke).
- [Handy Scripts](https://github.com/KigoJomo/handy-scripts) is an old but still useful drawer of image, scaffolding, and code-analysis scripts.
- [AQ Chat](https://github.com/KigoJomo/aq-chat) is a signed-in Gemini chat app with saved conversations and streamed replies. [Open the app](https://aqchat.vercel.app).

- [Mastertuple](https://mastertuple.co.ke) is a school learning platform for music and art lessons, practical work, exams, grading, and learner progress.
- [Experiments](https://experiments.kigo.ke) is where I publish small prototypes and keep their project notes in one place.
- [Sidekick](https://sidekick.aqutte.co.ke) is an AI assistant with persistent chats, Trello tools, approval controls, and usage billing.
